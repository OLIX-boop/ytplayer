# Assets

Aggiungi qui le seguenti immagini prima della build (sono referenziate in `app.json`):

- `icon.png` — 1024×1024 px (icona app)
- `splash.png` — 1284×2778 px o simile (splash screen iOS, su sfondo `#0a0a0f`)

Puoi anche generarle al volo da un singolo PNG con il tool `expo-icon-utils` o usare il template di default Expo.
Finché non aggiungi i file, Expo userà gli asset di default ma stamperà un warning.
